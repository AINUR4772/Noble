Возможности

Всё для игры — в одном окне

Ничего лишнего: лаунчер делает свою работу и не мешает. Подробнее — на странице «Возможности».

3D-просмотр скина

Модель игрока с анимациями «покой», «ходьба» и «вращение»: поворачивайте мышью, приближайте колесом.

Оптимизация игры

Высокая производительность GPU, Game Mode, план питания и приоритет процесса. Только обратимые настройки — с точкой отката.

Свои фоны

Добавьте любое изображение и настройте размытие, затемнение и насыщенность — с предпросмотром в реальном времени.

Без Microsoft-регистрации

Вход через Ely.by (по паролю или через браузер) либо офлайн-профиль. Никаких лишних аккаунтов.

Смена диска

Сборки и общие файлы игры переносятся на любой диск с прогрессом и отменой — системный диск не переполняется.

Моды с Modrinth

Поиск модов, ресурспаков и шейдеров, установка с зависимостями, поддержка .mrpack-модпаков.

Автообновления

Установленная версия обновляется сама. Portable-вариант можно обновлять вручную, новую версию — из Telegram.

Память, JVM- и игровые аргументы, версия загрузчика, отдельная Java для сборки, тёмный пиксельный интерфейс.

Установите и играйте

Установщик сам создаст ярлык «NobleLauncher», а папку установки можно выбрать на любом диске.

Noble Launcher 2.6.0 Инструкция по установке
  1. 1Скачайте установщик. Windows может показать предупреждение SmartScreen — «Подробнее» → «Выполнить в любом случае».
  2. 2Выберите диск. На странице каталога укажите любую папку — например, D:\NobleLauncher.
  3. 3Играйте. Выберите аккаунт Ely.by или офлайн-ник и запускайте сборку.
